# 提交规范

本项目使用 [Conventional Commits](https://www.conventionalcommits.org/zh-hans/) 规范提交信息，由 `commitlint` + husky `commit-msg` 钩子在提交时自动校验，格式不符会被拦截。

## 格式

```
<type>: <subject>
```

**注意**：`type` 后必须是**英文半角冒号 + 一个空格**，再跟描述。

## type 取值

| type       | 用途                                           |
| ---------- | ---------------------------------------------- |
| `feat`     | 新增功能                                       |
| `fix`      | 修复缺陷                                       |
| `docs`     | 文档变更                                       |
| `style`    | 不影响代码逻辑的格式调整（空格、分号、排版等） |
| `refactor` | 重构（既非新增功能也非修复缺陷）               |
| `perf`     | 性能优化                                       |
| `test`     | 测试相关                                       |
| `build`    | 构建系统或外部依赖变更                         |
| `ci`       | CI 配置或脚本变更                              |
| `chore`    | 杂项（依赖更新、配置调整等）                   |
| `revert`   | 回滚某次提交                                   |

## 常用模板

```bash
# 新增功能
feat: 新增登录页

# 修复缺陷
fix: 修复请求超时未提示的问题

# 文档变更
docs: 补充提交规范说明

# 格式调整
style: 统一缩进格式

# 重构
refactor: 抽取请求拦截器

# 性能优化
perf: 优化列表渲染性能

# 测试
test: 补充日期格式化单测

# 构建/依赖
build: 升级 vite 到 5.2.8

# CI
ci: 新增 GitHub Actions 工作流

# 杂项
chore: 更新依赖版本
```

## 可选：带 scope

```bash
# 如需标注影响范围，在 type 后加 (scope)
feat(api): 新增用户信息接口

fix(store): 修复计数器状态未重置
```

## 常见错误

| 写法               | 结果    | 原因                                            |
| ------------------ | ------- | ----------------------------------------------- |
| `chore: 更新配置`  | ✅ 通过 | 正确格式                                        |
| `chore:更新配置`   | ❌ 拦截 | 冒号后缺空格，报 `subject-empty`                |
| `chore：更新配置`  | ❌ 拦截 | 用了中文冒号，报 `type-empty`                   |
| `update: 更新配置` | ❌ 拦截 | `update` 不是合法 type                          |
| `更新配置`         | ❌ 拦截 | 缺 type 和冒号                                  |
| `feat(): 空 scope` | ✅ 通过 | 空 scope 被忽略，等价于无 scope（不推荐这么写） |

## 校验机制

- **`pre-commit`**：husky 调用 `lint-staged`，对暂存文件跑 `eslint --fix` + `prettier --write`。
- **`commit-msg`**：husky 调用 `commitlint` 校验提交信息格式。

如需绕过校验（应急用，不推荐）：

```bash
git commit --no-verify -m "提交信息"
```

## 相关配置

| 文件                           | 作用                       |
| ------------------------------ | -------------------------- |
| `commitlint.config.mjs`        | commitlint 规则配置        |
| `.husky/pre-commit`            | 提交前钩子（lint-staged）  |
| `.husky/commit-msg`            | 提交信息钩子（commitlint） |
| `package.json` → `lint-staged` | 暂存文件处理规则           |
